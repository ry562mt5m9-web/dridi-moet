# Part 1 – HTML Exercises (Absolute Beginner)

**How to work:**
1. Create a folder and a file named `index.html`.
2. Open it with a text editor (VS Code, Notepad, ...).
3. Save, then open the file in your browser (double-click it). Refresh after each change.

Solutions are in `04-corrections.md`. Try on your own first!

---

## Exercise 1 – Your first page
Create a page with the basic HTML structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
- The page title (browser tab) must be **"My First Page"**.
- The body must display: **Hello, World!**

## Exercise 2 – Headings and paragraphs
Write a page that contains:
- A main title (`h1`): "About Me"
- A subtitle (`h2`): "My hobbies"
- Two paragraphs: one introducing yourself, one about your hobbies.

## Exercise 3 – Text formatting
Write one paragraph in which:
- one word is **bold**
- one word is *italic*
- one word is <u>underlined</u>
- Add a line break in the middle of the paragraph.
- Add a horizontal line under the paragraph.

## Exercise 4 – Lists
Create:
1. An **unordered** (bullet) list of 4 fruits.
2. An **ordered** (numbered) list of the 3 steps to make a cup of tea.

## Exercise 5 – Links
Create three links:
1. A link to `https://www.wikipedia.org` that says "Visit Wikipedia".
2. The same kind of link, but it must open in a **new tab**.
3. An email link (`mailto:`) to `hello@example.com`.

## Exercise 6 – Images
Put an image on your page (download any picture and save it next to `index.html`, e.g. `cat.jpg`).
- Give it a width of 300 pixels.
- Add alternative text (`alt`) describing the image.
- Make the image a link to Wikipedia.

## Exercise 7 – A table
Create a table with 3 columns (Name, Age, City) and 3 rows of data.
The first row must use header cells (`th`).

## Exercise 8 – A simple form
Create a form with:
- A text field for "Name"
- An email field
- A password field
- Two radio buttons: "Yes" / "No"
- A checkbox: "I agree to the terms"
- A "Send" button

Each field needs a `<label>`.

## Exercise 9 – Page structure
Rebuild your page using semantic tags: `<header>`, `<nav>` (with 3 links), `<main>` (with an `<article>`), and `<footer>` (with a copyright text).

## Exercise 10 – Mini project: Your CV
Create a one-page CV that uses at least: a title, a photo, a short paragraph, a list of skills, a table of your education/experience, and a link to your email.
